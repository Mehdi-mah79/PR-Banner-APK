# پشتیبان‌گیری و بازیابی (Backup & Restore)

- **پشتیبان کامل (ZIP):** شامل فایل `manifest.json` (حاوی هش SHA-256 تک‌تک فایل‌ها)، فایل `data.json` و پوشهٔ `images/` حاوی تصاویر اصلی بنرهاست.
- **بازیابی ایمن:** پیش از اجرای بازیابی، ساختار آرشیو و صحت هش SHA-256 بررسی می‌شود و در حالت «جایگزینی (Replace)»، یک نسخهٔ پشتیبان ایمنی خودکار از داده‌های فعلی ثبت می‌گردد.
