# محیط ساخت و نسخه‌های ابزارها (Build Environment)

| ابزار / کتابخانه | نسخهٔ انتخاب‌شده | دلیل انتخاب و سازگاری |
| :--- | :--- | :--- |
| **Node.js** | `22.x LTS` | پشتیبانی کامل از Vite 6 و Capacitor 6 CLI در GitHub Actions |
| **Java JDK** | `21 (Temurin)` | نسخهٔ استاندارد مورد نیاز برای Android Gradle Plugin 8.x و Capacitor 6 |
| **Vite** | `^6.0.5` | باندلر سریع و استاندارد برای تولید فایل‌های استاتیک در پوشهٔ `dist/` |
| **React & TypeScript** | `18.3.1` / `5.7.2` | پایداری کامل با تمام کتابخانه‌های رابط کاربری و تایپینگ قوی |
| **Capacitor Core/Android** | `^6.2.0` | پشتیبانی رسمی از Android API 34+ و مدیریت مجوزهای اندروید ۱۳ و ۱۴ |
| **Local Notifications** | `^6.1.0` | زمان‌بندی اعلان‌های بومی اندروید با کانال اختصاصی |
| **GitHub Runner** | `ubuntu-24.04` | دارای Android SDK از پیش نصب‌شده و پایدار در GitHub Actions |
