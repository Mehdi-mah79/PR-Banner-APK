# مستندات تست خودکار (Automated Testing)

تست‌های واحد با استفاده از **Vitest** در پوشهٔ `tests/` قرار دارند و در هر بار اجرای GitHub Actions پیش از ساخت APK اجرا می‌شوند:
- `tests/calendar.test.ts`: تست تبدیل تاریخ شمسی و میلادی، سال‌های کبیسه (۱۴۰۳ و ۱۴۰۴)، طول ماه‌ها و بازه‌های زمانی.
- `tests/queries.test.ts`: تست جست‌وجوی فارسی، فیلترهای بایگانی و محاسبات آماری داشبورد.
